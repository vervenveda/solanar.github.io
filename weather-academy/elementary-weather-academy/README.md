# Khaemenes Elementary Weather Academy

## Weather 101–105

This package contains five complete 36-week elementary weather-science courses:

- **Weather 101 — Grade 1 recommendation · Weather Observer**
- **Weather 102 — Grade 2 recommendation · Weather Measurer**
- **Weather 103 — Grade 3 recommendation · Weather Data Scientist**
- **Weather 104 — Grade 4 recommendation · Weather Systems Engineer**
- **Weather 105 — Grade 5 recommendation · Atmosphere & Forecast Scientist**

The grade labels are recommended entry levels, not restrictions. Any elementary learner may take the course that matches current readiness.

Each course includes:

- 36 instructional weeks
- 5 learning days per week
- 180 daily mini-lessons
- 180 daily labs / investigations
- 180 printable worksheets
- 36 weekly mastery quizzes
- 80% weekly mastery to unlock the next week
- a 40-question cumulative final exam
- 80% final mastery
- a printable certificate of completion
- local progress storage
- game/tool connections to Solanar and Khaemenes learning applications
