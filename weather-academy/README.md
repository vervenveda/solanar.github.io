# Solanar Weather Academy

Solanar Weather Academy is a progressive weather and meteorology curriculum spanning elementary through high school.

## Course ladder

- Weather 101–105 — Elementary
- Weather 201–203 — Middle School
- Weather 301–304 — High School

Grade labels are recommended entry points. NAIB, mentors, parents and educators may route by readiness.

## Mastery

The middle/high-school repair architecture uses hard prerequisite gates:

daily exit ≥80% → weekly quiz ≥80% → six-week unit checkpoint ≥80% → final ≥80%.

A failed prerequisite blocks later work through the normal learner interface. The mentor brief identifies the current unmet prerequisite and instructs the mentor to remediate rather than advance.

## Recommended root files

Inside `weather-academy/`, use:

- `index.html` — the academy gateway
- `README.md`
- `mentor-manifest.json`

Then retain:

- `elementary-weather-academy/`
- `middle-weather-academy/`
- `high-school-weather-academy/`

No secrets or private credentials belong in these public files.
