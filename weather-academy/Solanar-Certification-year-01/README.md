# Solanar Professional Meteorology Certificate — Year I

A two-year, four-semester professional meteorology education pathway supporting three Year II specializations:

1. Operational Meteorology
2. Broadcast Meteorology
3. Climatology

This package contains the complete 36-week first year: Semesters I and II.

- `SEMESTER_1.md`

- `ASSESSMENT_AND_MASTERY.md`

- `UNIVERSITY_ALIGNMENT_NOTES.md`
- `curriculum.json`

## Mastery
Every required progression gate is 80%. Weak performance in one academic domain cannot be compensated for by a stronger grade in another.

## University-credit caution
This is a certificate curriculum and preparation framework. No private program can guarantee that every university will accept it for credit or allow a student to sit a university final. Receiving institutions make those decisions.

No secrets or private credentials are included.
